4Methodology

Leak-free evaluation protocol

  • Time-ordered train / validation / test split — no random shuffling, no future data in training features
  • Target-derived feature removed (is_discretionary)
  • User-level aggregates computed prior-only (expanding, shifted)
  • Preprocessing fitted on train only · fixed seed (42) · metrics logged to MLflow
  • Majority-class baseline (0.0456) reported next to every headline metric

Train / serve consistency

  • Meta-learner input assembled by a single shared contract function
  • Regression tests assert training and serving build identical meta inputs
  • Serving loads the exact artifacts evaluated here (models/serving/)
  • Known gap: serving features use single-transaction semantics — user-history aggregates are queued for parity work
