FinWise AI uses a LightGBM classifier for transaction categorization, a Prophet-based forecasting artifact, and a deterministic scipy-based budget optimizer driven by the financial profile you provide. Transaction classifications include model confidence, top-3 alternatives and SHAP feature attributions; budget and scenario logic is deterministic and testable.
